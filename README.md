## Technology

- Next.js and React
- TypeScript
- vinext and Cloudflare Workers-compatible output
- pnpm

## Run locally

Requires Node.js 22.13 or newer.

```bash
pnpm install
pnpm run dev
```

Validate a production build:

```bash
pnpm run build
node --test tests/rendered-html.test.mjs
```
