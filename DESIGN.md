# Website design system

This is a data engineering and applied AI services site for manufacturing, supply-chain, ecommerce and service teams. Visitors should understand the problem being solved and find a sensible first project.

## Identity

- Deep forest: `#07110e`; forest surface: `#132d27`.
- Warm cream: `#f8f4e9`; ink: `#1c1914`; brass: `#d7be80`.
- Use the gold-green SK monogram in `public/brand/sk-mark.svg`.
- Retain the existing approved brass-and-glass artwork as quiet supporting imagery.

## Type and layout

- Editorial serif for headings; existing Avenir/Helvetica system stack for body copy.
- Desktop hero headings: maximum 44px; side headings use two deliberate lines and the single-line middle heading centers vertically within that row.
- Mobile hero headings: 30px; stack each heading with its description.
- Body copy: 15–16px, with comfortable line height. Prefer one short, concrete sentence.
- Share edges consistently within each section. Use the existing five-percent desktop and seven-percent mobile gutters.
- Show one selected challenge and project at a time. Put detailed methodology behind an accessible disclosure.
- Use the customer’s operational language; describe a first project, its input and the way progress will be checked.

## Interaction and quality

- Semantic links, buttons, tabs and native disclosures; visible keyboard focus.
- At least 44px mobile navigation targets and readable select text.
- Honor reduced motion and offer pause controls for ongoing animation.
- Check at 320, 390, 768, 1024 and 1440px; no page overflow or overlapping navigation.
- Review the actual rendered page after every material visual change.

## Evidence and sharing

Keep employer experience separate from independent synthetic-data demonstrations. Preserve project limits and public source links.
